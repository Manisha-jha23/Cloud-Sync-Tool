# ☁️ Cloud Sync Tool

The **Cloud Sync Tool** is a web-based file storage and synchronization system built using **AWS Cloud Services**.  
It enables users to securely upload, store, and manage their files with automatic synchronization, user authentication, and email notifications.

---

## 🚀 Features
- 🔐 **User Authentication** — Secure signup and login using **AWS Cognito**
- 📁 **File Upload & Storage** — Upload, view, and delete files in **Amazon S3**
- 🗂️ **Metadata Management** — Store and retrieve file details from **AWS DynamoDB**
- 🔄 **Serverless APIs** — Backend logic handled using **AWS Lambda** functions and **Amazon API Gateway**
- 📧 **Email Notifications** — Automatic email confirmations using **AWS SES (Simple Email Service)**
- 🌐 **Modern Frontend** — Interactive React.js interface for managing files
- ☁️ **Scalable & Secure** — Fully serverless and hosted on AWS for reliability and performance

---

## 🧰 Tech Stack
**Frontend:** React.js  
**Backend:** Node.js / AWS Lambda  
**Database:** AWS DynamoDB  
**Storage:** AWS S3  
**API Management:** AWS API Gateway  
**Email Service:** AWS Simple Email Service (SES)
